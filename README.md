## 🗂️ Repository Structure

```
competitive_programming/
│
├── 📂 Arrays/                    # Array problems & sorting
├── 📂 Binary-Search/             # 1D, 2D arrays, search space
├── 📂 Strings/                   # String manipulation & pattern matching
├── 📂 Linked-Lists/              # Singly, doubly, medium & hard
├── 📂 Stacks-Queues/             # Stack, queue, monotonic stack
├── 📂 Trees/                     # Binary trees & BSTs
├── 📂 Heaps/                     # Priority queues & heap problems
├── 📂 Graphs/                    # BFS, DFS, shortest path, MST
├── 📂 Dynamic-Programming/       # All DP patterns & problems
├── 📂 Greedy/                    # Greedy strategies
├── 📂 Recursion-Backtracking/    # Pattern-wise recursion
├── 📂 Bit-Manipulation/          # Bitwise concepts & problems
├── 📂 Number-Theory/             # Primes, modular arithmetic, etc.
├── 📂 Combinatorics/             # Counting, permutations, etc.
├── 📂 Game-Theory/               # Sprague-Grundy, Nim, etc.
├── 📂 Geometry/                  # Computational geometry
├── 📂 Tries/                     # Prefix trees
├── 📂 Sliding-Window/            # Two pointer & window techniques
├── 📂 Math/                      # General math problems
├── 📂 Miscellaneous/             # Everything else
│
└── 📄 README.md
```

> **Convention:** Each solution file is named as `ProblemName_Source.cpp` (e.g., `TwoSum_Leetcode.cpp`, `Watermelon_CF.cpp`)
